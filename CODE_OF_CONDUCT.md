# Code of Conduct

Photon-QDrivers is intended to be a professional, research-friendly engineering
community for photonic quantum software, runtime systems, FPGA interfaces, and
hardware adapters.

## Expected Behavior

Contributors are expected to:

- Treat others with respect and patience.
- Keep technical criticism focused on code, designs, data, and assumptions.
- Welcome contributors from different backgrounds, disciplines, and experience
  levels.
- Be clear when a statement is opinion, an experiment, or a verified result.
- Disclose conflicts of interest when discussing vendor integrations,
  benchmarks, or hardware claims.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, intimidation, threats, or personal attacks.
- Insults based on identity, background, employer, nationality, race, religion,
  gender, sexual orientation, disability, or age.
- Publishing private information without permission.
- Repeated disruption of technical discussions.
- Misrepresenting benchmark results, hardware capability, or safety status.

## Research And Benchmark Integrity

Photon-QDrivers touches hardware, emulators, and performance claims. Contributors
must not present unverified estimates as measured results. Benchmarks should
include the device, simulator, software version, hardware platform, workload,
shots, precision settings, and measurement method wherever possible.

## Reporting

Report conduct concerns privately to the maintainers by opening a private
security advisory if available, or by contacting the project owner. Reports
should include relevant links, screenshots, logs, dates, and the names of people
involved.

Maintainers will review reports promptly, keep information as confidential as
practical, and take proportionate action. Actions may include clarification,
warnings, comment removal, temporary restrictions, or removal from the project.

## Scope

This code applies to project repositories, issue trackers, pull requests,
discussions, documentation, community channels, events, and any public space
where someone represents Photon-QDrivers.
