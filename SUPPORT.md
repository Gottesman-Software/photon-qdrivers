# Support

Photon-QDrivers is in active development. Use the following channels once the
repository is public:

- Bug reports: GitHub Issues.
- Feature proposals: GitHub Issues or Discussions.
- Security reports: follow [SECURITY.md](SECURITY.md).
- Questions about contribution workflow: GitHub Discussions.

## Before Asking For Help

Please include:

- Operating system and Python version.
- Package version or commit hash.
- Backend name, emulator, hardware target, or FPGA board.
- Minimal circuit or job that reproduces the issue.
- Full error message or relevant log output.
- Whether the target is a mock backend, emulator adapter, or real hardware.

## Scope

The core project can help with Photon-QDrivers code and adapter contracts. Vendor
SDK credentials, private QPU access, and hardware account issues should be
handled through the relevant vendor support channel.
